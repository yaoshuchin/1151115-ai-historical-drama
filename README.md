## 📖 平台與研習簡介

本平台為呂聰賢老師**「AI 歷史劇創作 × Google Flow 旗艦實戰研習」**（115年11月15日）之旗艦成果互動展示系統與完整實體檔案離線典藏庫。

全案以「重現千年歷史風華」為核心，貫徹 **AI 影片創作三劍客**：
1. **Google Gemini**：安裝自訂 `skill.md` 代理人（`@ai-video`），依據「4 小段、每段 8 秒、共 32 秒」標準公式產出電影級分鏡腳本。
2. **Google Flow (Veo 3.1)**：運用首尾幀（Start & End Frame）演算法與電影級鏡頭語言，搭配連續全自動生成指令，以最低點數消耗產出高穩定度動態片段。
3. **剪映 (CapCut)**：依循後製實戰九大步驟，整合視訊串接、文字轉語音、AI 自動辨識字幕、書法字幕描邊、古典配樂混音與成片輸出。

## 🎨 全域無障礙與東方美學體驗

1. **樂齡無障礙字級切換**：
   - 支援 **中 (16px)**、**大 (19px)**、**特大 (22px)** 三段根字級全局動態縮放。
2. **四色東方古典科技情境風格**：
   - 👑 **赤金華夏 (Imperial Crimson & Gold)**：預設典雅帝王紅與璀璨金，彰顯歷史史詩氣派。
   - 🌌 **玄武墨夜 (Obsidian Night)**：暗黑科技水墨深色，沉穩防眩光。
   - 🎋 **青巒竹影 (Bamboo Emerald)**：江南水墨青竹綠，如詩如畫。
   - 📜 **宣紙古籍 (Scroll Paper Light)**：古典古籍宣紙米白，高明度清爽閱讀。
3. **原生 Web Audio 純前端古典五音環境音樂引擎**：
   - 零外部音檔依賴，即時演算法合成宮、商、角、徵、羽空靈鐘鳴。

## 🔑 通行驗證規範

- 本站門禁安全遵循全域專案開發準則，前端全面採用原生 Web Crypto API 進行 SHA-256 雜湊驗證，不於靜態程式碼中存放任何明文字串。
- 通行碼請參照課堂研習公布之代碼（通行密碼：`nato`）。
- 頂部導航列右側設有「🔒 上鎖」功能按鈕，方便隨時切換安全保護狀態。

## 🚀 本機極速啟動方式

1. 點擊專案目錄下的 `start_local.bat`。
2. 系統將自動啟動 Python 本機伺服器並開啟瀏覽器：`http://localhost:8088/index.html`。
3. 即可在完全離線環境下流暢放映 107 頁簡報、播放 9 大歷史劇影片與配樂！
